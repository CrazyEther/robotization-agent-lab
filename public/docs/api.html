RIS Agent Studio — API

GET /api/v1/agent/health

Проверить работающий движок (JSON). Возвращает status, engine, capabilities, limits.

POST /api/v1/agent/study

Content-Type: application/json. Пример двух транспортных плеч с двумя станками:

{"input":{"sector":"warehouse","layout":{"width":20,"height":15,"pickup":{"x":2,"y":2},"dropoff":{"x":17,"y":12},"obstacles":[]},"workload":{"demandPerHour":6,"loadKg":80,"shiftHours":1},"robot":{"count":2,"payloadKg":250,"speedMps":0.8,"loadSeconds":10,"unloadSeconds":10,"batteryWh":2400,"chargeW":1000,"whPerMeter":0.25,"chargerCount":1},"mode":"fixed","seed":42},"operations":[{"id":"machine-1","label":"Обработка","x":7,"y":5,"durationSeconds":70,"capacity":1,"transformsLoad":true,"stochastic":false},{"id":"machine-2","label":"Контроль","x":12,"y":8,"durationSeconds":25,"capacity":1,"transformsLoad":false,"stochastic":false}],"clearanceMeters":0.15,"replications":5,"reworkProbability":0}

Ответ 200: scenarioHash; run.metrics, run.trace.events[], experiment.metrics, experiment.seeds, limitations. Ошибки входов/геометрии — HTTP 422.

Лимиты публичного сайта

До 90 заявок за прогон, до 15 роботов, максимум 2 часа модельного времени и 10 повторов, не более 5 технологических постов. Пользовательская геометрия и времена не представляют подтверждённые сведения о конкретном предприятии.

Другие маршруты

GET /api/v1/catalog — 44 карточки исходного каталога. POST /api/v1/ris/experiment — legacy SimPy, требует отдельного сервиса и в нынешнем публичном Worker недоступен. Новый агентный расчёт выполняется непосредственно в /agent/study.
